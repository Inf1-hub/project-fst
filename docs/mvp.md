# 逆光 MVP · 白石边境

本次范围：同一位面的五个连续战斗小关、一个职业流派、部分余晖与三档画质。
沿用设计文档 v3.2 的内容域目录、snake_case 和 Ability–Effect 配置组合。
美术采用用户选定的 **A：冷灰写实手绘**。

## 试玩

双击根目录 `run_game.cmd`，或在 Godot 4.7.2 中打开 `project.godot` 后按 F5。
点击「进入遗迹」开始，清剿当前房间。靠近余晖进入三选一，领取后前往地面出口按 **Enter**。
第 1–4 关继续同一位面的下一处战场；第 5 关击败主将及守军后，开启通往下一位面第 1 关的传送。

每层包含破营入口、折角侧院、断墙回廊、残军集结场、主将庭院五种布局，均在同一地面，不表现物理叠层。
下一位面目前复用这五种布局；敌人生命与伤害按位面提高，倍率有上限。每次换关保留构筑，恢复 35% 最大生命。
地图采用不规则边界、独立掩体和各自出入口；移除远景天空及悬空城垣，固定俯视方向、带死区的平滑跟随镜头，不拼接五关为一条长走廊。
死亡后可重新开始，构筑和层数重置。

| 输入 | 动作 |
| --- | --- |
| WASD / 鼠标 | 移动 / 瞄准 |
| 鼠标左键 | 持续挥斩 |
| 鼠标右键 | 正面格挡，消耗盾压；命中前 0.28 秒内举盾为精确格挡 |
| Space | 冲刺与短暂无敌，最多 4 次储备，逐步恢复 |
| Q | 盾击：伤害 + 眩晕 |
| E | 反击斩：精确格挡后窗口内释放 |
| R | 挑衅踏：嘲讽 + 减速 |
| F | 壁垒：短时减伤 + 回复 |
| C | 人类集结号角：加速 + 回复 |
| Tab | 显示 / 隐藏战术地图 |
| Esc | 暂停、三档画质、重试、退出 |
| F3 | 显示 / 隐藏 FPS 与实体数量统计 |
| Enter | 清场、领取余晖后在出口换关；第 5 关后传送 |

建议先用 Q 控制近战，再处理弓手；号手出现吹号预警时可用盾击打断。
百夫长红圈蓄力后造成范围伤害，半血后移动加快；可以冲刺脱离或正面精确格挡后按 E 反击。
盾压与冲刺次数是独立资源。

## 当前内容

- 五关初始分别有 4 / 5 / 5 / 6 / 5 个敌人；第五关含主将；包含剑盾步兵、弓手、巡逻号手。
- 号手存活时可召援；同屏总数上限 28，增援同时存活上限 8。
- 每关所有敌人（含增援）清空后掉落一次余晖，每位面共 5 次；领取前不可换关。
- 6 种余晖：盾墙回响、霜沿、震荡、归息、反击余韵、追风。
- 每次提供三种不同辉象；追加类最多融入 3 次，覆盖类一次即完成。
  已达上限的卡会明确显示恢复生命的替代收益，不继续添加效果。
- 暂停和选卡时停止战斗计时；画质设置保存在 `user://settings.cfg`。

## 配置与代码

| 文件 | 职责 |
| --- | --- |
| `data/mvp_settings.csv` | 生命、速度、盾压、冲刺、AI 时间、实体与对象池预算、层数倍率 |

| `combat/effects/effect_system.gd` | 共享伤害、回复、控制与增益原子 |
| `combat/abilities/ability_book.gd` | 施放、冷却、目标筛选、构筑修改 |

运行时能力使用深拷贝，不修改配置源。玩法 CSV 的导入模式为 Keep，避免被 Godot 当作翻译表。
当前直接读取 CSV；尚未实现完整编辑器导表插件、运行时补丁或正式存档系统。
路径导航使用启动时构建一次的静态 AStarGrid2D，AI 分批查询，不在战斗中重建导航。
后续扩展大地图时可替换为设计文档规划的烘焙 NavigationRegion2D。

## 画质与性能

| 项目 | 低 · 性能 | 中 · 均衡 | 高 · 精细 |
| --- | --- | --- | --- |
| 帧率上限 | 60 | 60 | 120 |
| 短时视觉效果预算 | 24 | 64 | 128 |
| 地面装饰 | 关闭 | 基础 | 增加 |
| 角色假阴影 | 关闭 | 开启 | 开启 |
| 敌人、碰撞、伤害预警 | 相同 | 相同 | 相同 |

三档均使用 Compatibility，保留垂直同步。高档帧率仍受显示器刷新率限制。
实测 GLES3 不支持 Godot 的 2D MSAA，因此没有暴露无效的 MSAA/TAA 开关。
角色导入尺寸限制为 512，当前地面、碎石、木栅与营地为 1024，使用 mipmap 与线性过滤；所有同类实体共享贴图。
地面使用单次纹理采样与颜色混合降低对比，没有动态灯光、全屏后处理或动态分辨率。

弹道固定 48 槽，视觉效果固定 128 槽；到上限复用或拒绝新增，不无限创建节点。
尸体短时淡出后释放；切换层时清理弹道、掉落与敌人。墙体只在初始化时产生碰撞体。
敌人按两人小队激活，避免首次接敌就唤醒全关。AI 近处 5 Hz 决策、远处 2 Hz，移动与战斗计时仍按 60 Hz 物理帧执行。
HUD 每秒刷新 10 次，静态地面只在画质变化时重绘。

性能原始记录见 `docs/benchmark.json`。该记录为本机 RTX 4060 Laptop、1920×1080、
28 个敌人、持续注入弹道和特效的短时测试。测试关闭帧率上限与 VSync，
每档运行 900 帧，剔除前 120 帧，记录主循环帧间隔；这不是纯 GPU 时间。
`static_memory_mb` 为 Godot 静态分配统计，不代表进程总内存或显存。
这不能证明 GTX 1060 达标，也不包含长时间温度、功耗或 1% Low 验收。

## 验证命令

```powershell
.\tools\godot.ps1 check
.\tools\godot.ps1 test
.\tools\godot.ps1 playtest
.\tools\godot.ps1 benchmark
```

`check` 验证引擎版本、导入和启动。`test` 同时验证五关推进、出生/敌人/出口连通、真实冲刺边界碰撞及奖励保留，并验证效果组合、格挡、冷却、掉落、
选卡、过关、实体上限与死亡重试。`playtest` 通过真实输入驱动正常生命与伤害的玩家，
实际连续战斗五关、领取余晖并传送至第二位面第一关；不使用秒杀或无限生命。
`benchmark` 会打开窗口，结果和日志存入 `.local/`。

可通过 Godot 的用户参数 `--seed=12345` 重现开局随机数与辉象抽取序列。
美术生成采用内置 image_gen，提示词与资源清单在 `source_assets/art_manifest.json`，
选定参考在 `source_assets/art_direction_a.png`，当前场景模块生成记录见 `source_assets/room_art_v3.json`。

## MVP 的美术与发行边界

采用冷灰碎石地、塌墙碎石堆、暗红旗木栅和破败营地的可复用分层拼装。外围与战斗区域共用连续地面，不再使用天空远景或悬空边界。实机仍有模块重复和静态动画的痕迹。
角色目前使用静态手绘精灵 + 转向翻转、步行动势、攻击摆动与命中特效，
还没有完整 8 向逐帧 / 骨骼动画；主将使用独立造型，玩家补充背面精灵，号手有独立识别标记。
音效为预生成缓存的合成提示，尚无正式配乐与录制音效。
这些是可试玩 MVP 资源，不能当作最终美术品质验收。

当前通过已安装的 Godot 运行，未生成独立 Windows 安装包。
本机匹配版本的导出模板目录为空；正式出包需安装 4.7.2 模板并配置 CSV 包含规则。


## 镜头与布局修订

取消将整间房缩放进一屏的固定中心相机。缩放从 0.8 调为 1.2，角色屏幕尺寸约为原来的 1.5 倍；1920×1080 设计分辨率下可见世界范围约为 1600×900。镜头使用 8% 拖拽死区和平滑跟随，不旋转。数值位于 mvp_settings.csv。

房间轮廓跨度扩大，增加有纵深的掩体组与错列木栅，形成入口缓冲、中心绕行和侧面接敌路线。世界范围为 2800×2400，实际可行走区域由各自多边形限定。寻路、碰撞、战术地图和相机边界同步按房间数据生成。

自动相机检查确认从入口到中段镜头实际移动，玩家仍在可见区域；五关实际输入通关与边界冲刺检查已通过。参考来源为 Supergiant 的 Hades II 官方演示页面；当前工具未能读取参考截图，因此这里的参数是本项目调校值，不是对原作镜头数值的测量。
